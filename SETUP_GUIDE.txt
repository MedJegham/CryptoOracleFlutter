STEP 1: INSTALL FLUTTER
================================================================================
If you don't have Flutter installed:

1. Download Flutter SDK from: https://flutter.dev/docs/get-started/install
2. Extract and add to PATH
3. Run: flutter doctor
4. Fix any issues reported

STEP 2: CLONE/OPEN PROJECT
================================================================================
cd crypto_oracle

STEP 3: INSTALL DEPENDENCIES
================================================================================
flutter pub get

This will download all required packages from pubspec.yaml

STEP 4: GENERATE CODE
================================================================================
flutter pub run build_runner build --delete-conflicting-outputs

This generates:
- *.freezed.dart files (for immutable models)
- *.g.dart files (for JSON serialization)

IMPORTANT: You must run this command before running the app!

STEP 5: RUN THE APP
================================================================================
# For Android emulator
flutter run

# For iOS simulator (Mac only)
flutter run -d ios

# For Chrome (web)
flutter run -d chrome

TROUBLESHOOTING
================================================================================

Problem: "Target of URI doesn't exist"
Solution: Run build_runner command (Step 4)

Problem: "No devices found"
Solution: Start an emulator or connect a physical device

Problem: "Gradle build failed"
Solution: 
- Check Android SDK is installed
- Run: flutter doctor
- Update Android SDK if needed

Problem: "CocoaPods not installed" (iOS)
Solution: 
- Install CocoaPods: sudo gem install cocoapods
- Run: cd ios && pod install

Problem: "Version solving failed"
Solution:
- Delete pubspec.lock
- Run: flutter pub get
